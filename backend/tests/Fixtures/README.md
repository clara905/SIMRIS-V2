# Fixture API aset

aset_api_contoh.json adalah **fixture sintetis**, bukan salinan API pengguna. API lokal dan file contoh asli belum tersedia (konfirmasi pengguna dalam sesi). Dataset ini berisi 197 baris buatan dengan profil tepi yang dijelaskan brief: inventaris kosong/ganda, seri ganda, kondisi, jumlah 12, tahun, dan catatan. Semua tes memakai Http::fake; tidak menghubungi API sungguhan. Ganti atau tambahkan sampel asli ketika tersedia sebelum verifikasi integrasi lokal.
